A Brief, Unnecessary History

The <blink> tag was introduced by Netscape in 1994. It did exactly one thing: make text blink, relentlessly, with no way to control the speed and no accessibility considerations whatsoever. Browser vendors eventually killed it out of mercy. We have brought it back here, using CSS @keyframes, purely so it can annoy you again.
