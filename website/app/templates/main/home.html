Featured Project PAYDAY BANK

PAYDAY BANK is a fictional bank where a compiled COBOL program owns every balance, customer, card and business rule, and a Flask app puts a modern web interface on top of it, with no database in between. Flask passes each operation to the core on the command line and reads back a single line. In November I redesigned the whole interface with Metro UI and gave a screen to every operation the core already knew how to do.

Python Flask GnuCOBOL Metro UI Docker Security
COBOL Banking Core
21 GnuCOBOL operations over indexed files, with packed-decimal balances and no database.
The Rules Live in the Core
COBOL checks ownership, status and balance of every account; scrypt passwords and CSRF on every form.
Accounts and Statements
Checking and savings accounts you can freeze or close, with a statement of every movement.
Transfers
Between your own accounts or to other customers, never revealing the recipient's balance.
Cards and Payments
Debit or credit cards with a per-purchase limit, a CVV shown only once and a simulated checkout.
New Interface, Same Core
A full Metro UI redesign: 57 files changed and a single line of COBOL logic.
