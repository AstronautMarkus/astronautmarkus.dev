Featured Project PAYDAY BANK

I built PAYDAY BANK, a fictional bank, as an end-to-end showcase of my web development and security skills. A COBOL subprocess simulates the original banking core, while a modern web layer handles accounts, transactions, and authentication on top of it. The result blends legacy technology with current tooling, with a focus on security and efficiency.

Python Flask COBOL PostgreSQL Security
COBOL Banking Core
A legacy subprocess that processes accounts and transactions like a real system.
Security First
Authentication, validation, and best practices against common vulnerabilities.
Transaction Management
Transfers, history, and real-time balances between accounts.
Hybrid Architecture
A bridge between old and modern technology inside a single application.
