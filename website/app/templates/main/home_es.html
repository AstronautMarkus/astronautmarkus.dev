Proyecto Destacado PAYDAY BANK

PAYDAY BANK es un banco ficticio donde un programa COBOL compilado es dueño de todos los saldos, clientes, tarjetas y reglas de negocio, y una app en Flask le pone encima una interfaz web moderna, sin base de datos de por medio. Flask le pasa cada operación al núcleo por línea de comandos y lee una sola línea de respuesta. En noviembre rediseñé toda la interfaz con Metro UI y le di pantalla a cada operación que el núcleo ya sabía hacer.

Python Flask GnuCOBOL Metro UI Docker Seguridad
Núcleo bancario en COBOL
21 operaciones en GnuCOBOL sobre archivos indexados, con saldos en decimal empaquetado y sin base de datos.
Las reglas viven en el núcleo
COBOL verifica propiedad, estado y saldo de cada cuenta; contraseñas con scrypt y CSRF en cada formulario.
Cuentas y cartolas
Cuentas corrientes y de ahorro que se congelan o cierran, con la cartola de cada movimiento.
Transferencias
Entre cuentas propias o a otros clientes, sin revelar nunca el saldo del destinatario.
Tarjetas y pagos
Débito o crédito con límite por compra, un CVV que se muestra una sola vez y un checkout simulado.
Interfaz nueva, mismo núcleo
Rediseño completo con Metro UI: 57 archivos cambiados y una sola línea de lógica COBOL.
