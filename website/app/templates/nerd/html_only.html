Why This Is Different From No-CSS

The No-CSS page proves this site's normal markup still reads fine with zero styling — it keeps the same <div> and class structure as every other page, just unstyled. This page goes further: it doesn't use <div> or class at all. Every element below is chosen because it actually describes what it contains.

What's Doing The Work Instead

Structure

<header>, <nav>, <main>, <article>, <section>, and <footer> replace what would normally be a pile of generic <div> wrappers.

Lists

  • Ordered content uses <ol>
  • Unordered content uses <ul>, like this one
  • Definitions use <dl>, <dt>, and <dd>
