No-CSS

This page loads zero stylesheets. Not "minimal CSS" — actually zero. No styles.css, no section-specific CSS, no Google Fonts, no Font Awesome CDN. What you're looking at right now is your browser's own default rendering of plain HTML tags, nothing else.

Why This Exists

Every other page on this site loads a shared stylesheet plus one page-specific file. It's easy to claim a site is "lightweight" while still shipping fonts, icon libraries, and a design system on every request. This page is the honest baseline: what does the actual content look like with none of that?

What's Actually Missing

  • No custom fonts — this is whatever monospace or serif your browser defaults to
  • No colors beyond default black text on a white background
  • No layout — headings, paragraphs, and lists stack exactly as written in the HTML
  • No dark mode, because there's no CSS to declare one
