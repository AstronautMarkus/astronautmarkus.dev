No-JS

Esta página no agrega ni una sola línea de JavaScript propia — sin bloque extra_js, sin <script> inline, nada. Mira el código fuente y compruébalo tú mismo.

Siendo completamente honestos: cada página de este sitio, incluida esta, carga un pequeño script compartido en el layout base que abre y cierra los dropdowns del nav — unas 10 líneas, presentes en todos lados, no específicas de esta página. Más allá de eso, nada aquí corre del lado del cliente. Todos los links funcionan, y todo formulario de este sitio que necesita enviar datos lo hace con un <form> HTML plano, sin necesitar llamadas fetch.
