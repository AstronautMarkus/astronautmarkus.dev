Text Mode

====================================================================

Lynx, w3m, and other text-mode browsers strip away images, fonts, and layout entirely, leaving just structure and links — numbered references instead of inline anchors. This page is a CSS homage to that look, not an actual text browser. It's still real HTML/CSS underneath.
